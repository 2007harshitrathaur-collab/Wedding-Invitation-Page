# 💍 Wedding Invitation Page

## Group 11 – Introduction to Computers Project

Welcome to our **Wedding Invitation Page** project! This is a simple and elegant wedding invitation website created using HTML, CSS, and JavaScript.

The main purpose of this project is to create a digital wedding invitation where visitors can explore information about the couple, view a photo gallery, and submit their RSVP response.

The website is designed to be simple, user-friendly, and responsive so that it can be viewed on both desktop and mobile devices.

## ✨ Features

Our website includes the following features:

### 1. Home Section
- Displays the wedding invitation introduction.
- Shows the couple's names.
- Provides a welcoming experience for visitors.

### 2. Navigation Bar
- Allows visitors to move between different sections.
- Includes a mobile-friendly navigation menu.

### 3. Couple Information
- Displays information about the couples.
- Presents the invitation in a clean and organized layout.

### 4. Event Details
- Provides space for wedding-related event information.
- Event dates and venue details are currently left blank because this project is a demonstration website.

### 5. Photo Gallery
- Displays a collection of photographs.
- Includes a lightbox feature to view images in a larger format.

### 6. RSVP Form
- Allows visitors to enter their response.
- Uses JavaScript for basic form validation.
- Displays a confirmation message after successful validation.

**Note:** The RSVP form currently works on the frontend only. Responses are not stored in a database or sent to a server.

### 7. Responsive Design
- Uses CSS to make the website suitable for different screen sizes.
- Provides a better viewing experience on mobile devices and desktops.

## 📂 Project Structure

The project is organized into the following files and folders:

```text
Wedding-Invitation-Page/
│
├── index.html
│
├── style.css
│
├── script.js
│
├── images/
│
└── README.md
```

### File Description

- **index.html:** Contains the main structure and content of the website.
- **style.css:** Contains the styling, layout, colours, fonts, and responsive design.
- **script.js:** Handles interactive features such as navigation, image gallery, and RSVP form validation.
- **images/:** Contains image assets used in the project.
- **README.md:** Provides information and instructions about the project.

## 🚀 How to Run the Project

You can run this project locally on your computer by following these steps:

**Step 1:** Download or clone this repository.

```bash
git clone https://github.com/2007harshitrathaur-collab/Wedding-Invitation-Page.git
```

**Step 2:** Open the downloaded project folder.

**Step 3:** Make sure the HTML, CSS, JavaScript, and image files are present in their correct locations.

**Step 4:** Open the `index.html` file in any modern web browser.

Alternatively, you can open the project in Visual Studio Code and use the Live Server extension.

No additional installation or framework is required.
